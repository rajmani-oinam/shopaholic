# Implementation Plan: Goal Dashboard — "Do It"

**Branch**: `001-goal-dashboard` | **Date**: 2026-02-16 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/001-goal-dashboard/spec.md`

## Summary

Build a single-page goal-tracking dashboard called "Do It" using Next.js App Router with a two-column layout (Current Goals / Completed Goals). Goals are persisted in localStorage, managed via React Context, and rendered with shadcn/ui components styled through Tailwind CSS with a custom pastel theme via `@theme`. Users can add goals (modal form with title + end date), complete them (checkbox → moves to Completed), and delete them (with confirmation). Goals approaching their deadline (≤ 3 days) get an amber highlight; overdue goals get a rose highlight. `date-fns` handles all date arithmetic.

## Technical Context

**Language/Version**: TypeScript 5.9.3 (strict mode enabled)
**Framework**: Next.js ^16.1.6 with App Router
**UI Library**: React ^19.2.4
**Styling**: Tailwind CSS v4 (CSS-based config, `@theme` directive) + shadcn/ui components
**Primary Dependencies**:
- `tailwindcss` (latest v4) — utility-first CSS framework
- `shadcn/ui` — accessible component primitives (Dialog, AlertDialog, Checkbox, Button, Card, Input, Label); source is copied into repo, not a runtime npm dependency
- `date-fns` (~3–5 kB tree-shaken) — `differenceInCalendarDays`, `format`, `startOfDay`, `isBefore`
- `clsx` + `tailwind-merge` — className composition (shadcn peer requirement)
- `lucide-react` — icon set (shadcn peer requirement)

**Storage**: Browser localStorage (no backend, no database)
**Testing**: None — per Constitution Principle V (NON-NEGOTIABLE)
**Target Platform**: Modern browsers (Chrome, Firefox, Safari, Edge), desktop + mobile
**Project Type**: Web application (single Next.js project)
**Performance Goals**: Dashboard renders in < 1 s; Lighthouse Performance ≥ 90
**Constraints**: Client-side only; no server-side state; < 200 kB total JS bundle (gzipped)
**Scale/Scope**: Single page, single user, unlimited goals (bounded by localStorage ~5 MB)

## Complexity Tracking

> Filled because Constitution Check Principle IV has a justified violation.

| Violation | Why Needed | Simpler Alternative Rejected Because |
|-----------|------------|-------------------------------------|
| shadcn/ui (6 components) | Provides accessible Dialog, AlertDialog, Checkbox with keyboard nav, ARIA, focus trap out of the box | Building from scratch would require reimplementing Radix primitives (~500+ LOC) for accessibility compliance; shadcn copies source into repo — no runtime dependency |
| date-fns (~3 kB gzipped) | Clean calendar-day difference, date formatting, startOfDay normalization | Native `Date` math is error-prone for calendar-day diffs across DST boundaries; `Intl.DateTimeFormat` lacks diff utilities |
| clsx + tailwind-merge | Required by shadcn's `cn()` pattern for className composition | Could use template literals but loses conditional class support and Tailwind conflict resolution |
| lucide-react | Icon set for delete button and empty-state illustrations; shadcn's default icon library | Could use inline SVGs but loses consistency and maintainability across components |
